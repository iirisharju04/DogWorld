Dog World

Dog World is a web application built with React. It allows users to explore different dog breeds, 
view pictures and compare information about different breeds.

Features:
- Browse a list of dog breeds.
- Search for dog breeds using Finnish names.
- View breed-specific information and image galleries.
- Add and remove breeds from favourites.
- Save favourites using the browser's localStorage, so they remain
saved after refreshing teh page.
- Compare two dog breeds based on their life expectancy, weight and height.

Technologies:
- React - Building the user interface and components
- React Router DOM - Navigation between pages
- Bootstrap - Styling and user interface elemnts
- CSS - Custom styling
- JavaScript - Application functionality and API requests
- Vite - Development environment and build tool

APIs:
The application uses two external APIs:
- Dog CEO API – Used to retrieve dog breeds and images.
- Dog API – Used to retrieve breed information, such as life expectancy, weight and height.

Running the project locally:
1. Clone the repository:
   git clone https://github.com/iirisharju04/DogWorld.git
2. Navigate to the project folder:
    cd DogWorld
3. Install dependencies:
    npm install
4. Start the development server:
    npm run dev
5. Open the local URL shown in the terminal
